## Fork scope

The generation keeps the fork-specific External PR authority because title/body issue-key matching can associate an unrelated Forgejo or other external PR. The fork path uses explicit authority data and exact identifiers while preserving upstream's issue-key convention for native flows.

PR [#203](https://github.com/yoyooyooo/multica/pull/203), `fix(integrations): restore task context for AGS`, is included as the final runtime commit. It restores the authenticated AGS execution-context endpoint with the closed v2 payload AGS consumes. The implementation derives claim and run identity from the Task UUID, strips client-supplied internal token-hash headers, verifies and locks the task token, and requires a running task. It does not restore the retired `execution_id` schema or its migration surface.
