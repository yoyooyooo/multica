zero queued/running autopilots. Both daemons reported zero active tasks and
`v0.4.37-31-g1ac10890c`. These observations are not a cutover authorization:
idle checks must run again immediately before switching each target.

`github.com -> Grok-Bot` rule, ahead of `Exit-GitHub`, and stalled. A temporary
SSH SOCKS tunnel through imile-win completed the fetch; it was stopped after
Sparkle's existing `127.0.0.1:17993` listener was independently verified. Further
Git operations use a per-command proxy override; shared routing was not changed.
