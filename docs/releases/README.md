# Releases

## Owns

- Immutable official release and fork-generation manifests.
- Accepted source identity, verification scope, artifact references, deployment evidence links, rollback source, and explicit claim limits.

## Must not own

- Mutable implementation or rollout progress.
- Product/architecture authority.
- Raw logs, credentials, or mutable environment snapshots.

## Read next

- [Fork generation manifests](fork-generations/README.md)

Tracker Issues and PRs own active work. A release manifest records accepted facts only after their evidence exists.
